# Quoc Binh Ngo — Portfolio

> Personal portfolio website of **Quoc Binh Ngo**, focused on Competitive Programming, problem solving, contest setting, and building things with code.

## Overview

This project is a personal portfolio website built from scratch with a focus on simplicity, performance, and a minimal developer-oriented aesthetic.

The website showcases:

- Competitive Programming profile and statistics
- Selected projects and coding work
- Programming templates and resources
- Personal introduction and contact information
- Dynamic Competitive Programming statistics

## Features

### Competitive Programming

The portfolio includes competitive programming profiles from:

- **Codeforces** — `@Quoc_Binhhh`
- **VNOI** — `@binhquocngo08092011`

Codeforces information is fetched dynamically and displayed on the website, including:

- Current rating
- Maximum rating
- Current rank

### Projects section

### Responsive Design

The website is designed to work across different screen sizes, with a responsive layout and clean typography.

### Minimal & Performance-focused

The project intentionally avoids heavy frameworks and dependencies.

It uses plain:

- HTML
- CSS
- JavaScript

This keeps the website lightweight and easy to maintain.
